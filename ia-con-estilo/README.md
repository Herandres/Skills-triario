# IA con Estilo — Visual Artifacts Library

A growing collection of premium interactive HTML artifacts built with Claude.
Each artifact is standalone — one file, no CDN, no server, opens in any browser.

---

## Philosophy

These aren't presentations. They're arguments.

When you open one of these artifacts in a browser, the audience understands what AI can do before you say a word. The visual quality is the message.

Each artifact teaches the next one. The `AGENTE_ESTILO_VISUAL.md` file is the accumulated design intelligence — it grows with every artifact built.

## Design system

Documented in `AGENTE_ESTILO_VISUAL.md`:
- Color palette (warm cream ground + terracotta accent)
- Typography pairing (Georgia serif + Courier New data)
- 7 signature elements: mesh, canvas, ticker, progress bar, reveal, typewriter, hero index
- Process: concept → build → critique → seal
- Known JS/CSS errors and fixes

---

## Key constraint

**CSP blocks all external URLs.** Everything must be inline: CSS, JS, SVG, fonts.
No CDN. No Google Fonts. No remote images. One self-contained file.
