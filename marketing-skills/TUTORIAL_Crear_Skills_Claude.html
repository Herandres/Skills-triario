una Skill en Claude.ai

Tutorial rápido para el equipo · Junio 2026
1
Ve a Habilidades y crea una nueva

En Claude.ai haz clic en tu perfil (esquina inferior izquierda) → Personalizar → Habilidades.
Luego clic en + → Crear habilidad → Escribe las instrucciones de la habilidad.

Las habilidades compartidas están disponibles para todo el equipo del proyecto.

2
Llena el formulario con el contenido del archivo .md

Se abre un formulario con tres campos. Copia el contenido del archivo `.md` de la skill (están en la carpeta loop-marketing-skills) y pégalo en Instrucciones.

Escribe las instrucciones de la habilidad
⚠ Este nombre es el comando — se activa escribiendo /ab-testing
⚠ Pega el contenido completo del archivo ab-testing.md aquí
¿Dónde están los archivos .md? En la carpeta loop-marketing-skills del repositorio del equipo. Hay 26 skills listas — cada archivo es el contenido de una skill. El nombre del archivo = el nombre del comando.
3
Activa los conectores MCP (una sola vez)

Los conectores permiten que las skills lean datos reales de HubSpot, ClickUp y M365. En una conversación haz clic en + → Conectores → activa los que necesitas.

4
Activa la skill escribiendo /comando

En cualquier conversación escribe /[nombre de la skill] y describe lo que necesitas. Claude activa la skill y entrega el resultado listo para revisar.

Ejemplos de uso
/ab-testing  necesito crear la hipótesis del sprint para Fepasde
/cro  audita esta landing page antes del lanzamiento: [URL]
/copywriting  escribe el brief del sprint — objetivo: más leads calificados, ICP: CFO industria
/ai-seo  diagnóstico AEO inicial para Internexa, sector telecomunicaciones B2B
