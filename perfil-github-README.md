# Hernán Castaño

Diseño y construyo agentes de IA aplicados a operaciones de agencia digital — automatizaciones que resuelven problemas reales de equipos que gestionan múltiples clientes.

Mi enfoque: antes de escribir un prompt, mapeo la arquitectura de los datos. El 60% del trabajo de un agente está en entender cómo está organizada la información — no en el texto del prompt.

## Lo que he construido

### Sistema de Inteligencia Operacional de Sprint
Pipeline que lee datos de gestión de proyectos, calcula KPIs operativos para cinco equipos y genera reportes visuales automáticos. Construido con Python, MCP ClickUp y Claude.ai. Operando en producción.

→ [ver repositorio](https://github.com/Herandres/sprint-intelligence-system)

### Kit de Construcción de Agentes
Framework de 8 prompts para diseñar agentes de IA desde cero — desde mapear la arquitectura de datos hasta validar el prompt en producción. Incluye 9 agentes construidos con el mismo framework, cada uno resolviendo un proceso real de agencia.

→ [ver repositorio](https://github.com/Herandres/Skills-triario)

### Kit de Skills de Marketing Digital
26 skills especializadas para equipos de marketing digital que operan con metodología de sprints — desde el diagnóstico AEO hasta la medición de resultados por experimento.

→ [ver repositorio](https://github.com/Herandres/marketing-skills-kit)
