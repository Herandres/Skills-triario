# Hernán Castaño

**Diseño y construyo agentes de IA aplicados a operaciones reales** — automatizaciones que resuelven problemas concretos de equipos que gestionan múltiples clientes simultáneamente.

Mi metodología: antes de escribir un prompt, mapeo la arquitectura de los datos.
El 60% del trabajo de un agente está en entender cómo está organizada la información — no en el texto del prompt.

## Cómo trabajo

```
Problema real  →  Arquitectura de datos  →  Contrato de prompt  →  Agente  →  Producción
```

No construyo demos. Cada agente en este repositorio opera o ha operado en un entorno de trabajo real,
con datos reales y equipos reales dependiendo de él.

**Lo que diferencia mi enfoque:**

- **Datos antes que prompt** — el primer entregable es siempre un mapa de la información, no un borrador de texto
- **Artefactos visuales como output** — los reportes son HTML interactivos que se abren en el browser, no PDFs
- **Documentación operativa** — cada skill incluye el prompt, la documentación y el manual de uso
- **Sistema, no herramienta** — diseño para que otros puedan operar el agente sin depender del que lo construyó
